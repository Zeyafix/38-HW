# Цены товаров в манатах

В файле [products.csv](products.csv) находятся 20 товаров с заголовками `id,name,quantity,currency,price`. `price` — цена одной единицы, `quantity` — количество единиц. Используются валюты `azn`, `usd`, `rub`, `eur`, `cnh`. Напишите программу `main.py`, которая получает курсы валют, переводит цены в азербайджанские манаты и сохраняет обновлённый каталог и его статистику.

Получите актуальные курсы с `https://api.frankfurter.dev/v2/rates` с параметром `base=azn`. Описание сервиса: [Frankfurter v2](https://frankfurter.dev/). Ответ — список записей с полями `date`, `base`, `quote`, `rate`. При базе `AZN` значение `rate` показывает, сколько единиц валюты `quote` соответствует одному манату. Например, выдуманная запись:

```json
{"date": "2026-10-22", "base": "AZN", "quote": "USD", "rate": 0.5}
```

означает, что 1 AZN соответствует 0.5 USD, а товар за 10 USD стоит 20 AZN. Цены, уже указанные в `azn`, остаются прежними. Коды валют могут отличаться регистром.

Запишите все товары в `products_azn.csv` с заголовками в таком порядке:

```csv
id,name,quantity,price
```

Сохраните идентификаторы, названия, количество и порядок строк исходного файла. В новом `price` укажите цену одной единицы в AZN с двумя знаками после точки. Округляйте к ближайшей сотой: если значение находится ровно посередине, округляйте вверх, например `1.005` → `1.01`. Курсы до пересчёта не округляйте.

По ценам из обновлённого каталога определите стоимость всех имеющихся единиц товаров, самый дешёвый и самый дорогой товар. Дешёвый и дорогой сравниваются по цене одной единицы, а общая стоимость учитывает количество. Товар с нулевым количеством тоже участвует в сравнении цен. Если цены совпали, выберите товар, который раньше встретился в исходном CSV.

Результаты сохраните в `summary.json`. Поле `currency` равно `AZN`, `total_cost` содержит общую стоимость, `cheapest_product` и `most_expensive_product` — выбранные товары с полями `id`, `name`, `quantity`, `price`. В JSON идентификаторы сохраняйте как текст, количество и денежные значения — как числа.

Например, при выдуманном курсе 0.5 USD за 1 AZN и таком маленьком каталоге:

```csv
id,name,quantity,currency,price
001,Notebook,3,azn,4.50
002,Mouse,2,usd,10.00
```

файл `products_azn.csv` будет содержать:

```csv
id,name,quantity,price
001,Notebook,3,4.50
002,Mouse,2,20.00
```

а `summary.json`:

```json
{
  "currency": "AZN",
  "total_cost": 53.5,
  "cheapest_product": {"id": "001", "name": "Notebook", "quantity": 3, "price": 4.5},
  "most_expensive_product": {"id": "002", "name": "Mouse", "quantity": 2, "price": 20.0}
}
```

Если используете сторонние пакеты, перечислите их в `requirements.txt`.

Если нужного курса нет, произошла ошибка соединения, сервер ответил HTTP-ошибкой или вернул некорректный JSON, выведите понятное сообщение на английском и завершите программу, не создавая и не изменяя файлы результатов. 

Исходный CSV оставьте без изменений. Файлы сохраняйте в UTF-8; разделитель CSV — запятая, дробная часть отделяется точкой.

Ввод с клавиатуры не нужен. После успешной записи выведите сообщение на английском с именами обоих файлов, например:

```text
Saved products_azn.csv and summary.json
```
